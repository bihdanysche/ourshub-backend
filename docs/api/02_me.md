# Me Module API Documentation

> **Base Path:** `/me`  
> **Security Model:** Exclusively `HttpOnly`, `Secure`, `SameSite=Lax` Cookies. Requires active session (`access_token`).

---

## Quick Reference

| Method | Endpoint | Access | Purpose |
|---|---|---|---|
| `PATCH` | `/me` | `@AuthRequired()` | Updates user display name and/or username |

---

## 1. Endpoints Detail

### `PATCH /me`
Updates profile information (`name` and/or `username`) for the currently authenticated user.

- **Access:** `@AuthRequired()`
- **Cookies Required:** `access_token`
- **Request Body (`EditProfileDto`):**
  ```json
  {
    "name": "Alex Smith",
    "username": "Alex_Dev"
  }
  ```

#### Field Validation Rules:

| Field | Type | Required | Constraints |
|---|---|---|---|
| `name` | `string` | Optional | Length: 1–30 chars.<br>Cannot start or end with whitespace.<br>Cannot be only spaces.<br>Allows any Unicode characters. |
| `username` | `string` | Optional | Length: 3–30 chars.<br>Must start with a Latin letter (`[a-zA-Z]`).<br>Allowed characters: `a-z`, `A-Z`, `0-9`, `_`, `.`.<br>Cannot contain spaces.<br>Must be globally unique (case-insensitive). |

- **Behavior & Uniqueness:**
  - If no fields are provided in the payload (`{}`), returns `400 Bad Request` with `EMPTY_UPDATE_PAYLOAD`.
  - The `username` is saved preserving the user's input case (e.g. `"Alex_Dev"`), while uniqueness is enforced against `username_lower` (`"alex_dev"`).
  - A user can change the casing of their own existing username (e.g., from `"alex_dev"` to `"Alex_Dev"`) without triggering a conflict.
  - If the requested username is already registered by another user (in any case variation), returns `409 Conflict` with `USERNAME_ALREADY_TAKEN`.

- **Success Response (200 OK):**
  ```json
  {
    "id": 1,
    "username": "Alex_Dev",
    "name": "Alex Smith",
    "avatar": "https://example.com/avatar.jpg"
  }
  ```

#### Errors:
| Status | Error Code | Description |
|---|---|---|
| `400 Bad Request` | `BAD_REQUEST` | Validation failed (e.g., invalid regex, invalid length, spaces in username). |
| `400 Bad Request` | `EMPTY_UPDATE_PAYLOAD` | Request body is empty (`{}`). At least one field must be provided. |
| `401 Unauthorized` | `UNAUTHORIZED` | No valid session or `access_token` cookie provided. |
| `409 Conflict` | `USERNAME_ALREADY_TAKEN` | The chosen username is already taken by another user. |

---

## 2. Error Codes Dictionary (`MeErrorCode`)

| Error Code | Status | Meaning | Recommended Client Action |
|---|---|---|---|
| `EMPTY_UPDATE_PAYLOAD` | `400` | No update fields provided in request body. | Provide `name` and/or `username`. |
| `USERNAME_ALREADY_TAKEN` | `409` | Username is already registered by another account. | Prompt user to pick a different username. |
